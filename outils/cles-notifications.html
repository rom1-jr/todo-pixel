Clés de notification

Cette page crée la paire de clés qui permet à GitHub d'envoyer le récap du matin à ton iPhone. Tout se passe dans ton navigateur : rien n'est envoyé nulle part.

Garde la clé privée pour toi : colle-la seulement dans les secrets GitHub, puis ferme cette page. Si tu régénères des clés, il faudra réactiver le récap sur ton iPhone.
